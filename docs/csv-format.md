# CSV Format

`import:csv` ожидает CSV, где каждая строка описывает одну позицию исторического заказа.

Обязательные колонки:

- `dedupe_key` — уникальный ключ исторического заказа.
- `finalized_at` — дата финализации в ISO-формате.
- `share_basket_url` — ссылка корзины; можно оставить пустой.
- `item_name` — название позиции.
- `quantity` — количество позиции.
- `item_xml_id` — `xml_id` товара; можно оставить пустым.
- `item_price` — цена позиции; можно оставить пустой.

Правила:

- строки с одинаковым `dedupe_key` объединяются в один исторический заказ;
- внутри одного `dedupe_key` значения `finalized_at` и `share_basket_url` должны совпадать;
- импорт идемпотентен по `dedupe_key`;
- `--skip-duplicates` пропускает уже импортированные заказы;
- `--fail-on-row-error` запрещает частичный импорт и завершает команду с ошибкой, если есть хотя бы одна проблемная строка.

Пример:

```csv
dedupe_key,finalized_at,share_basket_url,item_name,quantity,item_xml_id,item_price
order-2026-05-13-a,2026-05-13T10:00:00.000Z,https://vkusvill.ru/?share_basket=1,Бананы,2,731,168
order-2026-05-13-a,2026-05-13T10:00:00.000Z,https://vkusvill.ru/?share_basket=1,Сыр Серанто,1,991,359
order-2026-05-14-b,2026-05-14T19:30:00.000Z,,Яблоки,3,812,149
```
