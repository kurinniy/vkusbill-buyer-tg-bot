# Vkusvill MCP Workflow

- Всегда используй MCP-сервер `vkusvill` для задач по поиску товаров, просмотру деталей товара и сборке корзины ВкусВилл.
- Для данных по товарам предпочитай MCP-инструменты, а не веб-поиск.
- Перед подбором корзины уточняй ключевые ограничения: состав, количество, бюджет, аллергены, калорийность и другие важные предпочтения.
- Если нужно выбрать варианты, предлагай понятные альтернативы по цене, рейтингу и калорийности, когда это уместно.
- Отвечай пользователю по-русски.
